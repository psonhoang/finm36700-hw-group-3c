## Submission

Submit the two executed notebooks:

- `HW6_Smart_Beta.ipynb`: graded Sections 2 and 3, including the cross-sectional tests.
- `HW6_Momentum.ipynb`: graded Sections 2.1–2.5.

Each notebook contains the English answers, calculation code, and saved results. READING and EXTRA sections are excluded.

## Data and results

Keep the two course workbooks next to the notebooks:

- `factor_pricing_data.xlsx`: monthly factor and industry excess returns, January 1980–April 2025.
- `momentum_data.xlsx`: monthly momentum data, January 1927–August 2025. Assignment tables use observations through December 2024.

`results/` contains the required result tables and the cumulative momentum chart. Running the notebooks recreates these files. Returns in CSV files are decimals; notebook tables display percentages where appropriate.

## Run

Install the packages in `requirements.txt` in your Python environment, select that environment as the notebook kernel, and run each notebook from top to bottom. No separate Python scripts are needed.

```sh
python -m pip install -r requirements.txt
```
